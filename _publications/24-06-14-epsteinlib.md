EpsteinLib is a C library and Python package designed for the fast and efficient computation of the (regularized) Epstein zeta function and the (regularized) anisotropic Epstein zeta function for arbitrary real parameters. 
It supports arbitrary lattices, dimensions, wavevectors, shiftvectors and power-law interactions and includes Python, Julia and Mathematica bindings.
A python package (epsteinlib) available via `pip install epsteinlib` for easy integration.

For more information on the properties of the Epstein zeta function and the underlying algorithm, please refer to our manuscript <a href="https://doi.org/10.1093/imanum/drag057">10.1093/imanum/drag057</a>.
